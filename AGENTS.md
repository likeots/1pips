# AGENTS.md

## Project Overview
This project evaluates whether **adding +1 pip to stop-loss** improves win rate for trades generated by a **minimal SMC (Smart Money Concepts) BOS-only strategy** on historical tick data.

We run a **paired simulation** per trade:
- **Base**: stop set strictly **beyond** the protective swing (swing low for longs, swing high for shorts) + margin.
- **Plus1**: same trade with **stop +1 pip wider**.  
Take-profit (TP) is unchanged across variants. We then compare outcomes and compute **McNemar’s exact test** on discordant pairs.

## Data
- **Input CSV (ticks):** `time,bid,ask`
  - `time`: ISO8601 (timezone allowed)
  - `bid, ask`: floats
- The script internally resamples ticks to **M1 OHLC** using midprice `(bid+ask)/2`.

## Core File
- **`one_pip_stop_sensitivity.py`** — single, self-contained script:
  - Builds M1 candles.
  - Detects swings & BOS (no external SMC libs).
  - Generates entries immediately after BOS.
  - Places SL strictly beyond protective swing (+margin).
  - Sets TP by either **fixed RR** or **opposite swing** (configurable).
  - Simulates base vs +1 pip stop outcomes on tick stream.
  - Outputs detailed CSV + summary + McNemar p-value.

## Agent Roles

### 1) **Architect Agent**
- Define minimal, deterministic SMC logic (swings + BOS).
- Keep code < 300 lines, no external SMC dependencies.
- Specify CLI, outputs, edge cases, and acceptance tests (see below).

### 2) **Data Agent**
- Robustly parse times: try `format='ISO8601'`, then fallback to mixed parse.
- Clean data: sort by time, drop invalid rows/dupes.
- Resample ticks → M1 OHLC with **uppercase** columns: `Open,High,Low,Close`.

### 3) **Strategy Agent (SMC-Minimal)**
- **Swings** with lookback `k`:
  - Swing high at `i` if `High[i]` strictly greater than highs of previous `k` and next `k` bars.
  - Swing low analogously.
- **BOS**:
  - **Bullish BOS** when `Close[i] > last_swing_high_price`.
  - **Bearish BOS** when `Close[i] < last_swing_low_price`.
- **Entry**:
  - On BOS bar `i`, entry time is the next minute (`i+1`) if it exists; otherwise use `i`.
  - Map that minute timestamp to **nearest subsequent tick index**.
  - Long at **ask**, short at **bid**.
- **Sessions (optional)**:
  - If enabled, allow only UTC hours `[07..17]`.

### 4) **Risk Agent (SL/TP)**
- **Stop strictly beyond protective swing**:
  - Long: protective swing = last swing **low** → `stop_price = swing_low - sl_margin_pips * pip`.
  - Short: protective swing = last swing **high** → `stop_price = swing_high + sl_margin_pips * pip`.
  - Require `stop_pips > 0` and `>= min_sl_pips`.
- **Take Profit modes**:
  - `tp-mode=rr`: `tp_pips = stop_pips * rr`, `rr ∈ [0.5, 3.0]`.
  - `tp-mode=swing`: opposite swing beyond extreme:
    - Long: `tp_price = last_swing_high + tp_margin_pips * pip`.
    - Short: `tp_price = last_swing_low  - tp_margin_pips * pip`.
  - Require `tp_pips > 0` and `>= min_tp_pips`.

### 5) **Simulator Agent**
- Iterate forward in ticks from `entry_idx`:
  - **Long**: SL hit if `bid ≤ stop_price`; TP hit if `bid ≥ tp_price`.
  - **Short**: SL hit if `ask ≥ stop_price`; TP hit if `ask ≤ tp_price`.
  - If neither hit by end of data → count as **loss** (explicit).
- For each trade, compute outcomes for:
  - **base stop**
  - **base stop + 1 pip**

### 6) **Analytics Agent**
- Compute:
  - Trades count.
  - Base & Plus1 win rates.
  - Delta (Plus1 − Base).
  - **McNemar’s exact test**:
    - `b = (lost_base & won_plus1)`
    - `c = (won_base & lost_plus1)`
    - Two-sided exact p-value via binomial tail.
- Save `one_pip_results_detailed.csv` with:
  ```
  entry_time, direction, entry_price,
  swing_stop_price, stop_price_base, stop_price_plus1,
  tp_price, stop_pips, tp_pips,
  won_base, won_plus1
  ```

## CLI Spec
```
--csv <path>                  # required
--pip-size <float>            # required (e.g., 0.0001 for EURUSD)
--swing-lookback <int>        # default 3
--sessions on|off             # default off (UTC 07..17 if on)
--sl-margin-pips <float>      # default 1.0 (distance beyond swing)
--tp-margin-pips <float>      # default 1.0 (only for tp-mode=swing)
--min-sl-pips <float>         # default 2.0
--min-tp-pips <float>         # default 2.0
--tp-mode rr|swing            # default rr
--rr <float>                  # default 1.0 (tp-mode=rr)
--tf <int>                    # default 1 (use every Nth trade)
```

## Edge Cases & Rules
- Missing/op-parseable times → drop; always sort by time.
- Duplicate timestamps → drop duplicates (ticks and M1 index).
- If no opposite swing available at BOS → skip trade.
- Non-positive `stop_pips` / `tp_pips` → skip trade.
- Mapping M1 entry to ticks: **clamp index** into valid range.
- Empty result set still prints a valid summary with zeros.

## Output Artifacts
- `one_pip_results_detailed.csv` — per-trade diagnostics.
- Console summary — counts, WRs, delta, McNemar b/c, p-value.
- `tqdm` progress bar over simulated trades.

## How to Run (example)
```bash
python one_pip_stop_sensitivity.py \
  --csv EURUSD-2025-09_converted.csv --pip-size 0.0001 \
  --swing-lookback 3 --sessions off \
  --sl-margin-pips 1.0 --min-sl-pips 2.0 \
  --tp-mode rr --rr 1.0 --min-tp-pips 2.0 \
  --tf 1
```

## Acceptance Criteria
- Generates non-zero trades on realistic tick data (when present).
- SL is **always** strictly beyond protective swing + margin (by construction).
- Produces correct per-trade CSV and clear summary with McNemar exact p-value.
- No external SMC libs; code is clean, documented, and under ~300 LOC.
