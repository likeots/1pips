# One Pip Stop Sensitivity Simulator

Этот репозиторий содержит скрипт `one_pip_stop_sensitivity.py`, который симулирует трейды по правилам Break of Structure (BOS) с проверкой чувствительности стоп-лосса на один пункт.

## Требования

- Python 3.9+
- Установленные пакеты: `pandas`, `numpy`, `tqdm`

Установить зависимости можно через:

```bash
pip install -r requirements.txt
```

или напрямую:

```bash
pip install pandas numpy tqdm
```

## Подготовка данных

Скрипт ожидает CSV-файл с тиковыми данными и колонками `time`, `bid`, `ask`. Временная метка должна быть в формате ISO8601 (допускаются разные варианты, таймзона опциональна).

## Запуск симуляции

Базовый пример запуска:

```bash
python one_pip_stop_sensitivity.py \
  --csv path/to/your_ticks.csv \
  --pip-size 0.0001 \
  --swing-lookback 3 \
  --sessions off \
  --sl-margin-pips 1.0 \
  --min-sl-pips 2.0 \
  --tp-mode rr \
  --rr 1.0 \
  --min-tp-pips 2.0 \
  --tf 1
```

Ключевые аргументы:

- `--csv` – путь к входному CSV с тиками (обязательный параметр).
- `--instrument` – символьное имя инструмента (например, `EURUSD`, `XAUUSD`, `BTCUSD`).
- `--pip-size` – размер пункта для инструмента (например, 0.0001 для EURUSD).
- `--swing-lookback` – параметр поиска свингов (по умолчанию 3).
- `--sessions` – `on` для фильтрации сделок по UTC [07..17], иначе `off`.
- `--sl-margin-pips` – запас в пунктах за защитным свингом.
- `--min-sl-pips` и `--min-tp-pips` – минимальные расстояния до стопа и тейк-профита.
- `--tp-mode` – `rr` (фиксированное соотношение риск/прибыль) или `swing` (противоположный свинг).
  Для совместимости принимаются синонимы `symmetric` → `rr` и `structure` → `swing`.
- `--rr` – коэффициент риск/прибыль для режима `rr`.
- `--tf` – брать каждую N-ю сделку (по умолчанию 1 – брать все).

Полный список аргументов можно получить командой:

```bash
python one_pip_stop_sensitivity.py --help
```

## Результаты

После завершения симуляции создаётся набор структурированных файлов:

- `one_pip_results_<INSTRUMENT>.csv` – основной детализированный CSV по инструменту (например,
  `one_pip_results_EURUSD.csv`). Файл дублируется под историческим именем `one_pip_results_detailed.csv`
  для обратной совместимости.
- `one_pip_results_summary.json` – агрегированная сводка с ключевыми метриками по каждому инструменту и
  объединёнными результатами.

Колонки CSV сгруппированы по смыслу:

- `entry_time`, `direction`, `entry_price`
- `protective_swing` – экстремум свинга, использованный для постановки стопа
- `stop_price_swing`, `stop_pips_swing` – рабочий стоп за свингом с учётом запаса
- `stop_price_plus1`, `stop_pips_plus1` – вариант стопа, расширенный на один пункт
- `tp_price`, `tp_pips`
- `won_swing`, `won_plus1`

В консоль выводится сводка по количеству сделок, винрейтам для свингового стопа и варианта +1 пункт, а также p-value точного критерия МакНемара. Для очень малых вероятностей значение выводится в научной нотации (например, `1.42E-12`), чтобы избежать появления искусственных нулей из-за округления. Итоговые показатели также сохраняются в `one_pip_results_summary.json`, что упрощает последующую визуализацию.

## Веб-дэшборд

Для интерактивного анализа результатов доступен модуль `viz_dashboard.py`. Он визуализирует показатели
по нескольким инструментам, поддерживает фильтрацию по диапазону дат и автоматически обновляет графики при
появлении новых симуляций.

### Дополнительные зависимости

Для запуска дэшборда установите Plotly и Dash (в дополнение к базовым зависимостям скрипта):

```bash
pip install plotly dash
```

### Запуск

1. Выполните симуляцию для одного или нескольких инструментов (например, `EURUSD`, `XAUUSD`, `BTCUSD`).
2. Запустите веб-приложение:

   ```bash
   python viz_dashboard.py
   ```

3. Откройте указанный в консоли адрес (обычно `http://127.0.0.1:8050/`).

На дэшборде доступны:

- сравнение винрейтов для базового свингового стопа и варианта со стопом +1 пункт;
- распределение размеров стопов и тейк-профитов в пунктах;
- таймлайн исходов сделок;
- таблица с результатами точного критерия МакНемара (b, c, p-value) для каждого инструмента и объединённой выборки.

Выбор инструментов осуществляется через выпадающий список, временной фильтр — через календарь. Если после
очередной симуляции появляются новые файлы `one_pip_results_<INSTRUMENT>.csv` или обновляется сводка, интерфейс
перезагружает данные автоматически (каждую минуту либо при ручном обновлении страницы).
