# One Pip Stop Sensitivity Simulator

Этот репозиторий содержит скрипт `one_pip_stop_sensitivity.py`, который симулирует трейды по правилам Break of Structure (BOS) с проверкой чувствительности стоп-лосса на один пункт.

## Требования

- Python 3.9+
- Установленные пакеты: `pandas`, `numpy`, `tqdm`

Установить зависимости можно через:

```bash
pip install -r requirements.txt
```

или напрямую:

```bash
pip install pandas numpy tqdm
```

## Подготовка данных

Скрипт ожидает CSV-файл с тиковыми данными и колонками `time`, `bid`, `ask`. Временная метка должна быть в формате ISO8601 (допускаются разные варианты, таймзона опциональна).

## Запуск симуляции

Базовый пример запуска:

```bash
python one_pip_stop_sensitivity.py \
  --csv path/to/your_ticks.csv \
  --pip-size 0.0001 \
  --swing-lookback 3 \
  --sessions off \
  --sl-margin-pips 1.0 \
  --min-sl-pips 2.0 \
  --tp-mode rr \
  --rr 1.0 \
  --min-tp-pips 2.0 \
  --tf 1
```

Ключевые аргументы:

- `--csv` – путь к входному CSV с тиками (обязательный параметр).
- `--pip-size` – размер пункта для инструмента (например, 0.0001 для EURUSD).
- `--swing-lookback` – параметр поиска свингов (по умолчанию 3).
- `--sessions` – `on` для фильтрации сделок по UTC [07..17], иначе `off`.
- `--sl-margin-pips` – запас в пунктах за защитным свингом.
- `--min-sl-pips` и `--min-tp-pips` – минимальные расстояния до стопа и тейк-профита.
- `--tp-mode` – `rr` (фиксированное соотношение риск/прибыль) или `swing` (противоположный свинг).
  Для совместимости принимаются синонимы `symmetric` → `rr` и `structure` → `swing`.
- `--rr` – коэффициент риск/прибыль для режима `rr`.
- `--tf` – брать каждую N-ю сделку (по умолчанию 1 – брать все).

Полный список аргументов можно получить командой:

```bash
python one_pip_stop_sensitivity.py --help
```

## Результаты

После завершения симуляции создаётся файл `one_pip_results_detailed.csv` с колонками, сгруппированными по смыслу:

- `entry_time`, `direction`, `entry_price`
- `protective_swing` – экстремум свинга, использованный для постановки стопа
- `stop_price_swing`, `stop_pips_swing` – рабочий стоп за свингом с учётом запаса
- `stop_price_plus1`, `stop_pips_plus1` – вариант стопа, расширенный на один пункт
- `tp_price`, `tp_pips`
- `won_swing`, `won_plus1`

В консоль выводится сводка по количеству сделок, винрейтам для свингового стопа и варианта +1 пункт, а также p-value точного критерия МакНемара. Для очень малых вероятностей значение выводится в научной нотации (например, `1.42E-12`), чтобы избежать появления искусственных нулей из-за округления.
